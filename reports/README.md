# Evaluation outputs

Run `python -m app.train` followed by `python -m app.evaluate` to generate:
- `evaluation.json`: accuracy, macro precision, macro recall, macro F1, and per-class report
- `predictions.csv`: held-out examples with actual and predicted labels
- `confusion_matrix.csv`: confusion matrix

These outputs are intentionally not fabricated or committed as precomputed model results. They are generated from the locally trained model. Add screenshots of the running Streamlit app and the evaluation output here after running the project.
